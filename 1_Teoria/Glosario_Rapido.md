# Glosario Rápido de Automatización

1. JSON = El formato de transporte (un texto ordenado con clave y valor).
2. Pydantic = El inspector (asegura que los datos sean del tipo correcto: texto, número, lista).
3. SQLite = El almacén (guarda los datos en tablas).
4. Try / Except = El paracaídas (si la API de Gemini falla, el código no se rompe y reintenta).
5. Batch / Lote = La cinta transportadora (procesa varios archivos uno detrás de otro).
